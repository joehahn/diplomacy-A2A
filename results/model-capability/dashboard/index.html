Model-capability axis: the 7-game rotation

Opus (frontier) and MiMo (budget) each rotate through all seven powers once, on opposite sides of the board, against a Sonnet field. Counterbalancing board position across 7 games isolates the model from the seat. Games run 3 years (S1901–W1903A).

Plots derived from the seven game transcripts by experiments/model_capability/build_axis_dashboard.py. Per-game dashboards and the negotiation transcripts live under each game's own folder.
