# linkedin/

LinkedIn posts about the project. One file per post, `YYYY-MM-DD-slug.md`.

Keep the draft text and, once posted, the live URL and any notable engagement,
so the post history lives in one place. The running theme across posts is the
positioning goal: "I make multi-agent (A2A) systems legible and steerable,"
demonstrated through this project's build → measure → diagnose → fix → verify
loop.
