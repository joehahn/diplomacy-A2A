# communications/

Outward-facing communications about this project: social posts, blog
articles, and conference materials. Kept in the repo so the writing lives
next to the work it describes, and so abstracts and slides are visible to
visitors.

- **`linkedin/`** — LinkedIn posts (drafts and published), one file per post.
- **`blog/`** — longer-form articles / blog posts.
- **`conferences/`** — one subfolder per event: abstract, slides, talk notes.

Conventions:
- Name files with a `YYYY-MM-DD-slug` prefix so they sort chronologically.
- At the top of each file note its status (draft / submitted / published) and,
  once live, the canonical URL.

Note: this repo is public (GitHub Pages serves it), so anything committed here
is visible. That is intended for finished abstracts, slides, and published
posts. If you want to keep in-progress drafts private until they ship, keep
them in a gitignored `communications/drafts/` (or local-only) until ready.
