# conferences/

One subfolder per event, named `YYYY-MM-event-slug/` (e.g.
`2026-09-pydata-nyc/`). Each holds:

- `abstract.md` — the submitted talk/poster abstract (markdown renders on
  GitHub).
- `slides.pdf` or `slides.md` — the deck. Commit the PDF so it is downloadable
  straight from the repo.
- `notes.md` — optional speaker notes, demo script, or follow-up links.

At the top of `abstract.md` note the submission status (submitted / accepted /
declined / presented) and the event date and location.
