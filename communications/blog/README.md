# blog/

Longer-form articles about the project. One file per piece,
`YYYY-MM-DD-slug.md`. If cross-posted (Medium, Substack, personal site),
record the canonical URL at the top.

Good candidate topics, each a transferable lesson rather than game trivia:
- Agent observability: interrogating a finished agent about its own decisions
  (the `ask` tool).
- Steering emergent multi-agent behavior: diagnosing passive equilibria and
  fixing them with measured prompt changes (the KPI before/after).
- Reproducible, low-cost multi-agent evaluation.
